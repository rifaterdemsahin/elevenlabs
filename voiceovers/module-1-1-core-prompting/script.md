### Scene 02: The Four Key Components
**Audio:** `scene-02.mp3`  
**Tone:** Clear, articulate  
> When working with Large Language Models, clarity isn't just about good grammar... it's about system architecture. Effective prompts contain four key components: a clear **Role**, rich **Context**, an explicit **Task**, and strict **Constraints**. When we wrap these components inside structured input formats like Markdown or JSON, we eliminate ambiguity and make outputs deterministic.

### Scene 06: Three-Step Implementation & Guardrails
**Audio:** `scene-06.mp3`  
**Tone:** Step-by-step, measured  
> First, declare the context using system tags. Second, place the raw meeting transcript inside clear XML or Markdown block quotes so the AI knows where the data starts and ends. Third, specify the exact schema for the response. Notice how setting constraints—like "If a deadline is unknown, output null"—prevents the model from guessing or hallucinating dates.
